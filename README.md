# WhatsApp Animated UI 💬

A WhatsApp-inspired animated web project built using HTML, CSS and AOS Animations.

## Features

- WhatsApp-inspired user interface
- Smooth animations
- Interactive chat elements
- Responsive layout
- Clean and modern design


## Technologies Used

- HTML
- CSS
